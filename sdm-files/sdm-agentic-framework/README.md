# Service Delivery Manager Agentic Framework

AI-powered agents to support the Service Delivery Manager (SDM) job function.

## Purpose

Automate and augment SDM workflows through intelligent agents that handle:
- Status reporting and stakeholder communication
- Risk identification and escalation
- Resource planning and allocation
- Customer engagement tracking
- Delivery milestone management
