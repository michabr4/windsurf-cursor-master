# CIRCUIT / Cisco API Notes

This template includes starter files based on the original note in [CIRCUIT_API.txt](../CIRCUIT_API.txt).

## What The Original Note Shows

The note includes two separate patterns:

1. a Bridge OAuth client-credentials request
2. a Cisco-hosted chat call pattern using app metadata and an API key

## What The Starter Files Do

- load values from `.env`
- request a Bridge access token
- build a simple chat request payload
- keep naming consistent across Python and Node so the examples are easy to compare

## Important Reminder

These examples are templates, not production-ready enterprise integrations. They are meant to be understandable and safe starting points.
