# Tool Guide

This template supports several AI coding tools. This page points to the official documentation for each one.

## GitHub Copilot In VS Code

What it is: AI help built into Visual Studio Code for chat, inline edits, code suggestions, agent mode, and tool use.

Read first:

- https://code.visualstudio.com/docs/copilot/reference/copilot-vscode-features
- https://code.visualstudio.com/docs/copilot/getting-started

Use it if: you want a familiar editor with strong built-in chat and agent workflows.

## Cursor

What it is: an AI-first code editor with agent workflows, planning, repo understanding, and repo-level rules.

Read first:

- https://cursor.com/docs/get-started/quickstart
- https://cursor.com/docs
- https://cursor.com/docs/rules

Use it if: you want a dedicated AI editor with strong repo navigation and customization.

## Windsurf

What it is: an AI editor with onboarding designed for importing from VS Code or Cursor and working quickly with built-in AI features.

Read first:

- https://docs.windsurf.com/windsurf/getting-started
- https://docs.windsurf.com/

Use it if: you want an editor focused on fast AI-assisted flow and easy migration from VS Code-style tooling.

## Claude Code

What it is: Anthropic's coding agent that can work from the terminal, VS Code, desktop, web, and other surfaces.

Read first:

- https://code.claude.com/docs/en/overview
- https://code.claude.com/docs/en/quickstart
- https://code.claude.com/docs/en/memory

Use it if: you want a strong agentic workflow and clear repo-level guidance through `CLAUDE.md` and related docs.

## OpenCode

What it is: an open-source AI coding agent that works in the terminal and also integrates with IDEs.

Read first:

- https://opencode.ai/docs/
- https://opencode.ai/docs/ide/
- https://opencode.ai/docs/agents/

Use it if: you want an open tool with terminal-first workflows and project guidance through `AGENTS.md`.

## How This Repo Uses Tool Docs

This repository gives you local instructions for this specific template.

The official links above are the right place to learn:

- installation
- keyboard shortcuts
- account setup
- troubleshooting
- advanced features
- changing product behavior as tools evolve
