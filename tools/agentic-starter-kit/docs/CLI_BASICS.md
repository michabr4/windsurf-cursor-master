# CLI Basics

Use this page if words like CLI, terminal, command, or shell still feel unfamiliar.

## What A CLI Is

A CLI is a Command Line Interface.

Plain language: it is a text-based way to tell a computer or tool what to do.

Instead of clicking buttons, you type commands.

## Simple Mental Model

Think of a CLI like a chat box with strict rules:

- you type a command
- the tool runs that command
- the tool prints a result back

Unlike normal chat, the command has to match what the computer expects.

## Common CLI Terms

- Terminal: the window where you type commands
- Command: the instruction you type
- Output: the text the command prints back
- Folder or directory: the place you are currently working in
- Script: a saved command shortcut, often run by tools like `npm`

## How This Repo Uses CLI

This repo uses the CLI for simple tasks like:

- running a sample
- installing Node packages
- activating a Python virtual environment if someone chooses that path
- starting tools like Claude Code or OpenCode

## Why CLI Matters For Agents

Many coding agents can use the CLI for you.

That means an agent can:

- run a sample
- inspect files
- install dependencies when needed
- show you the result of a command

In beginner terms: the agent can use the terminal as one of its tools, instead of only editing files.

## What Beginners Usually Need To Remember

- Commands run in the current folder.
- Small typing differences matter.
- Some commands only work after setup is complete.
- It is normal to copy and paste starter commands at first.
- You do not need to memorize everything before using the repo.
