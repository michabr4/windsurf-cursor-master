# NetPilot

A starter project for network automation experiments and tooling.

## Structure

- `netpilot/` - core package
- `tests/` - test placeholders and future test suites
- `requirements.txt` - Python dependencies

## Quick Start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m netpilot
```
