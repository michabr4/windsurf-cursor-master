NetPilot 5.0 — Performance Tracking Core

Tracks learner performance across lessons, labs, quizzes, workflows, and scenarios.

- Completion Time
- Attempts
- Error Types
- Hint Usage
- Telemetry-Based Behavior
- Confidence Indicators

Performance Events:
- lesson_completed
- lab_completed
- quiz_attempted
- workflow_executed
- remediation_triggered
